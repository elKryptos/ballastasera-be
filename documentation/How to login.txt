Para probar en Postman:                                                                                                                                                                                                                                                                                                                                     

El login con Google no se puede iniciar bien desde Postman porque el primer paso es un flujo de navegador completo (redirect a Google, pantalla de consentimiento, cookies de sesión). 
  Postman no maneja eso limpiamente contra un endpoint oauth2Login de Spring Security. El flujo correcto para testear es:                                              

  1. En el navegador (no Postman): ir a http://localhost:8080/oauth2/authorization/google, logueate con tu cuenta Google real.                                                                                                                                                                                                                              
  2. Spring te redirige, CustomOidcUserService crea/actualiza tu usuario en la BD, y OAuth2LoginSuccessHandler devuelve un JSON en el navegador:                                                                                                                                                                                                              
  { "token": "eyJhbGciOi...", "tokenType": "Bearer", "userId": "...", "email": "...", "displayName": "...", "role": "USER" }                                                                                                                                                                                                                                  
  3. Copia el token de esa respuesta.                                                                                                                                                                                                                                                                                                                         
  4. En Postman, para probar endpoints protegidos (ej. GET http://localhost:8080/api/auth/me): pestaña Authorization → tipo Bearer Token → pega el token.
	O header manual Authorization: Bearer <token>.                                                                                                                                                      

No hay nada que "insertar" a mano en Postman para el login en sí — el paso 1 tiene que ser navegador, el resto (endpoints protegidos con el JWT) sí es 100% Postman.  
  
Te detallo el flujo completo, endpoint por endpoint, para implementar en Angular.                                                                                                                                                                                                                                                                           

  1. Iniciar login (botón "Iniciar sesión con Google")                                                                                                                                                                                                                                                                                                        

  No es una llamada HTTP con HttpClient — es una navegación completa del browser, porque tiene que pasar por la pantalla real de Google.                                                                                                                                                                                                                      

  // auth.service.ts                                                                                                                                                                                                                                                                                                                                          
  loginWithGoogle(): void {                                                                                                                                                                                                                                                                                                                                   
    window.location.href = 'http://localhost:8080/oauth2/authorization/google';                                                                                                                                                                                                                                                                               
  }                                                                                                                                                                                                                                                                                                                                                           

  <button (click)="loginWithGoogle()">Iniciar sesión con Google</button>                                                                                                                                                                                                                                                                                      

  2. Google redirige de vuelta al backend (automático, no lo tocás)                                                                                                                                                                                                                                                                                           

  Google → http://localhost:8080/login/oauth2/code/google → Spring Security valida, CustomOidcUserService crea/actualiza el Users en la BD → OAuth2LoginSuccessHandler genera el JWT y hace:                                                                                                                                                                  

  302 redirect → http://localhost:4200/oauth2/callback?token=eyJhbGciOi...                                                                                                                                                                                                                                                                                    

  3. Ruta de callback en Angular — acá recuperás el token                                                                                                                                                                                                                                                                                                     

  Necesitás una ruta que capture ese redirect:                                                                                                                                                                                                                                                                                                                

  // app.routes.ts                                                                                                                                                                                                                                                                                                                                            
  { path: 'oauth2/callback', component: OAuth2CallbackComponent }                                                                                                                                                                                                                                                                                             

  // oauth2-callback.component.ts                                                                                                                                                                                                                                                                                                                             
  export class OAuth2CallbackComponent implements OnInit {                                                                                                                                                                                                                                                                                                    
    constructor(private route: ActivatedRoute, private router: Router) {}                                                                                                                                                                                                                                                                                     

    ngOnInit(): void {                                                                                                                                                                                                                                                                                                                                        
      const token = this.route.snapshot.queryParamMap.get('token');                                                                                                                                                                                                                                                                                           
      if (token) {                                                                                                                                                                                                                                                                                                                                            
        sessionStorage.setItem('token', token);                                                                                                                                                                                                                                                                                                               
        this.router.navigate(['/']); // o a tu dashboard/home                                                                                                                                                                                                                                                                                                 
      } else {                                                                                                                                                                                                                                                                                                                                                
        this.router.navigate(['/login']); // algo falló                                                                                                                                                                                                                                                                                                       
      }                                                                                                                                                                                                                                                                                                                                                       
    }                                                                                                                                                                                                                                                                                                                                                         
  }                                                                                                                                                                                                                                                                                                                                                           

  4. Interceptor — agrega el token a TODAS las llamadas API automáticamente
  
    Esto evita repetir el header a mano en cada servicio:                                                                                                                                                                                                                                                                                                       

  // auth.interceptor.ts                                                                                                                                                                                                                                                                                                                                      
  export const authInterceptor: HttpInterceptorFn = (req, next) => {                                                                                                                                                                                                                                                                                          
    const token = sessionStorage.getItem('token');                                                                                                                                                                                                                                                                                                            
    if (token) {                                                                                                                                                                                                                                                                                                                                              
      req = req.clone({                                                                                                                                                                                                                                                                                                                                       
        setHeaders: { Authorization: `Bearer ${token}` }                                                                                                                                                                                                                                                                                                      
      });                                                                                                                                                                                                                                                                                                                                                     
    }                                                                                                                                                                                                                                                                                                                                                         
    return next(req);                                                                                                                                                                                                                                                                                                                                         
  };                                                                                                                                                                                                                                                                                                                                                          

  // app.config.ts                                                                                                                                                                                                                                                                                                                                            
  providers: [                                                                                                                                                                                                                                                                                                                                                
    provideHttpClient(withInterceptors([authInterceptor]))                                                                                                                                                                                                                                                                                                    
  ]                                                                                                                                                                                                                                                                                                                                                           

  5. Al arrancar la app — hidratar el usuario con /api/auth/me                                                                                                                                                                                                                                                                                                

  // auth.service.ts                                                                                                                                                                                                                                                                                                                                          
  getCurrentUser(): Observable<UserDto> {                                                                                                                                                                                                                                                                                                                     
    return this.http.get<UserDto>('http://localhost:8080/api/auth/me');                                                                                                                                                                                                                                                                                       
    // el interceptor ya le puso el Bearer token                                                                                                                                                                                                                                                                                                              
  }                                                                                                                                                                                                                                                                                                                                                           

  Llamalo en un APP_INITIALIZER, en el ngOnInit del componente raíz, o en un AuthGuard — lo importante es que se dispare una vez al cargar la app (o al entrar a rutas protegidas) para saber quién está logueado y popular el estado global (nombre, avatar, rol).                                                                                           

  6. Manejar el 401 (token vencido/inválido) — logout automático                                                                                                                                                                                                                                                                                              

  Otro interceptor (o catchError en el primero) que, si una respuesta da 401, limpia el sessionStorage y redirige a /login:                                                                                                                                                                                                                                   

  export const errorInterceptor: HttpInterceptorFn = (req, next) => {                                                                                                                                                                                                                                                                                         
    const router = inject(Router);                                                                                                                                                                                                                                                                                                                            
    return next(req).pipe(                                                                                                                                                                                                                                                                                                                                    
      catchError((err: HttpErrorResponse) => {                                                                                                                                                                                                                                                                                                                
        if (err.status === 401) {                                                                                                                                                                                                                                                                                                                             
          sessionStorage.removeItem('token');                                                                                                                                                                                                                                                                                                                 
          router.navigate(['/login']);                                                                                                                                                                                                                                                                                                                        
        }                                                                                                                                                                                                                                                                                                                                                     
        return throwError(() => err);                                                                                                                                                                                                                                                                                                                         
      })                                                                                                                                                                                                                                                                                                                                                      
    );                                                                                                                                                                                                                                                                                                                                                        
  };                                                                                                                                                                                                                                                                                                                                                          

  7. Endpoints de negocio (eventos, favoritos, etc.)                                                                                                                                                                                                                                                                                                          

  Una vez armado el interceptor del punto 4, cualquier endpoint nuevo que crees en el backend (protegido por anyRequest().authenticated()) ya funciona automáticamente desde Angular sin código extra de auth — solo llamás el servicio HTTP normal y el token va solo.                                                                                       

  ---                                                                                                                                                                                                                                                                                                                                                         
  Resumen del ciclo completo:                                                                                                                                                                                                                                                                                                                                 
  1. Botón → window.location.href a /oauth2/authorization/google                                                                                                                                                                                                                                                                                              
  2. Google + backend hacen su magia → redirect a /oauth2/callback?token=...                                                                                                                                                                                                                                                                                  
  3. Angular guarda el token en sessionStorage                                                                                                                                                                                                                                                                                                                
  4. Interceptor mete el token en cada request                                                                                                                                                                                                                                                                                                                
  5. /api/auth/me al arrancar para poblar el usuario en pantalla                                                                                                                                                                                                                                                                                              
  6. 401 en cualquier momento → logout automático
